# UI Specification: ReliefHub AI
**Version:** 1.1 (Updated with Streamlined Donor Flow)
**Design System:** Material 3 (Clean, accessible, data-dense but readable)

## 1. Global Brand & Theme
* [cite_start]**Primary Color:** `#1A56A0` (Trust Blue) - Used for primary buttons, active tabs, headers[cite: 367].
* [cite_start]**Secondary Color:** `#0D7377` (Operational Teal) - Used for secondary actions, data visualizations[cite: 367].
* [cite_start]**Error/Alert Color:** `#991B1B` (Urgent Red) - Used for CRITICAL runway items and Scarcity zones[cite: 367].
* **Warning Color:** `#F59E0B` (Amber) - Used for WARNING/MONITOR runway items.
* **Safe Color:** `#10B981` (Green) - Used for SAFE runway items and Abundance zones.
* **Typography:** Google Fonts 'Inter'. Clean, modern sans-serif.
* **Layout:** Responsive (Mobile-first, scales to Web/Tablet dashboards). 

---

## 2. Role-Based Navigation
The navigation menu (Sidebar for web, BottomNav for mobile) dynamically changes based on user role.

### 2.1 Donor Navigation (Minimalist Flow)
*As per recent UX updates, Donors have a restricted, hyper-focused UI.*
* **Active Drives** (Default route on login)
* **Donation History**
* *(Note to UI Generator: Ensure Donors cannot see or access the Grid, Ledger, or Admin dashboards).*

### 2.2 NGO Admin / Staff Navigation
* **The Ledger** (Inventory & Runway)
* **The Grid** (Geo-Spatial Mapping)
* **The Scout** (AI Dashboard - Admin Only)
* **Active Campaigns** (Replenisher Drives)

---

## 3. Screen Specifications

### 3.1 Authentication (All Roles)
* **Login/Register Screen:** Centered card layout. Beautiful gradient logo (`#1A56A0` to `#0D7377`). Clean email/password inputs with validation styling. Role selection dropdown on the Register screen.

### 3.2 Donor Screens
* [cite_start]**Active Drives (Feed):** * **Layout:** A scrollable, visually engaging feed of "Proactive Drive" cards[cite: 331].
    * [cite_start]**Card UI:** Needs to display the Item Name, a Gemini-generated reason string (e.g., "Rice stocks projected to run low in 18 days"), Days Remaining badge, and a visual Progress Bar (Qty Pledged vs Qty Needed)[cite: 329, 333].
    * [cite_start]**Action:** A prominent "Pledge Items" button[cite: 334]. [cite_start]No urgent red colors here; keep it calm and proactive[cite: 317].
* [cite_start]**Donation History:** * **Layout:** Clean data table or list view[cite: 369].
    * **Columns/Data:** Date, User, Drive ID, Category, Status (Pledged/Delivered). 

### 3.3 Admin & Staff Screens
* **The Ledger (Inventory Dashboard):**
    * [cite_start]**Top Bar:** Summary stats (Counts of Critical, Warning, Monitor, Safe items)[cite: 378].
    * [cite_start]**List View:** Grouped by Category (e.g., CAT-01 Basic Necessities)[cite: 291].
    * [cite_start]**Row UI:** SKU Name, Current Stock, and a highly visible "Days of Runway" pill/badge colored Red, Amber, or Green[cite: 295, 376]. 
    * [cite_start]**Actions:** "Stock In" and "Stock Out" buttons opening a clean modal/bottom sheet[cite: 377].
* **The Grid (Map View):**
    * [cite_start]**Main Area:** Full-screen or large container for Google Maps[cite: 384].
    * [cite_start]**Overlays:** UI legend floating on the map (Red = Scarcity, Grey = Neutral, Green = Abundance)[cite: 391].
    * **Interaction:** Tapping a sector opens a bottom-sheet sliding up. [cite_start]The sheet must display Sector ID, Risk Scores by Category, and Demographic Data cleanly[cite: 389].
* **The Scout (AI Intelligence - Admin Only):**
    * [cite_start]**Top Section:** "Run Scout" manual trigger button (prominent) and "Last Run" timestamp[cite: 401, 403].
    * [cite_start]**Chart Area:** A bar chart showing Runway Days for all SKUs (using `fl_chart` styling)[cite: 404].
    * [cite_start]**Log Feed:** A sleek, terminal-like or card-based scrollable list showing Gemini's JSON risk reasoning (converted to readable text)[cite: 402].

## 4. Specific Component Requirements
* **Runway Badges:** Need to be instantly recognizable. 
    * `< 7 Days` = Red background, white text + Alert Icon.
    * `7-30 Days` = Amber background, black text.
    * `> 30 Days` = Green background, white text.
* **Loading States:** Use shimmer effects for data loading, especially for the Ledger and Active Drives feeds.
